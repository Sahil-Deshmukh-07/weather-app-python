# Weather App

A simple desktop weather application built using Python and Tkinter that fetches real-time weather data using the OpenWeatherMap API.

## Features
- Real-time weather information
- Simple GUI using Tkinter
- Weather data using OpenWeatherMap API
- Displays:
  - Temperature
  - Feels Like Temperature
  - Humidity
  - Weather Description

## Technologies Used
- Python
- Tkinter
- Requests
- OpenWeatherMap API
